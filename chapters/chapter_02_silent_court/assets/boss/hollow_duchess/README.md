# Hollow Duchess original asset provenance

All assets in this directory are original project-owned work generated from the low-resolution Godot `Image` source in `scripts/tools/generate_hollow_duchess_assets.gd` or authored as the adjacent SVG concept. No downloaded, AI-generated, traced, or commercial-game material is used.

- Production frame canvas: 96×96 RGBA8, transparent.
- Rendering: nearest-neighbour, no mipmaps, integer-scale review.
- Direction: source art faces right; `AnimatedSprite2D.flip_h` provides left-facing presentation.
- The SVG is a real concept reference, not a runtime substitute. Runtime sprites are the PNG sequences under `sprites/`.
